# Sspillowy Pulse

**Nombre del proyecto:** Sspillowy Pulse  

**Descripción:** Plataforma web y móvil para el monitoreo y gestión en tiempo real con integración de asistente inteligente y autenticación segura con backend en producción. Proyecto desarrollado para la entrega del proceso de Títulos Duoc UC - Ingeniería Informática (Sede Alameda).

---

## Tecnologías utilizadas

* **Frontend / Mobile:** Flutter Web & Mobile, Dart
* **Cliente HTTP:** Dio Client
* **Backend API:** FastAPI (Python), OAuth2 (form-urlencoded)
* **Hosting / API:** Domain Prod (`https://api.sspillowy.com`)
* **Control de versiones:** Git & GitHub

---
